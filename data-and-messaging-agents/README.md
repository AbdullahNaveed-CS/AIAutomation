# Multi-Channel Data Analysis & AI Chat Agents

Automated data ingestion, natural-language analytics, and cross-platform messaging workflows connecting **Telegram**, **Gmail**, and **n8n**.

## Included Workflows
* **`Complete Telegram + Gmail data analysis workflow.json`:** Pulls incoming reports/messages from Gmail and Telegram, runs automated data parsing and summarization, and delivers insights back to the user.
* **`Complete Telegram data analysis workflow.json`:** Dedicated Telegram bot pipeline for querying datasets and receiving structured analytical summaries on mobile.
* **`Complete workflow of data analysis.json`:** Core ETL and automated statistical summary pipeline.
* **`AI Chat Agent.json`:** Memory-enabled conversational AI assistant with tool-calling capabilities.

## Setup
1. Import the `.json` file into n8n (**Workflows → Import from File**).
2. Connect your **Telegram Bot Token**, **Gmail OAuth2**, and AI model credentials.
